  - Python USD API 自动化流水线开发与测试。

### 2. 长期管线架构顾问 (Pipeline Retainer)
- **交付形式**：月度 / 季度保留金顾问服务（Retainer）；
- **服务内容**：关键技术方案评审、痛点排查架构诊断、Asset Resolver 2.0 统一解析中台落地指导、疑难 Bug 攻坚。

## 预约与评估流程

为了保证服务交付质量与时间精力的有效聚焦，我们通过问卷机制进行前期需求摸底：

1. **提交需求调研表**：填写 [《工业级管线架构与技术顾问需求评估表》](https://wj.qq.com/s2/openusd_consulting)；
2. **初步技术评估**：收到问卷后 48 小时内对工程痛点进行可行性评估并回复技术诊断概要；
3. **闭门方案对齐**：与企业技术总监 (TD) 进行 30 分钟技术方案与排期对齐，制定正式内训/顾问合同。
